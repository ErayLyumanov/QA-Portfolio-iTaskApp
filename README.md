# QA Portfolio – iTaskApp Testing Project

This repository contains my manual QA testing project for the iTaskApp platform.

The goal of this project is to demonstrate practical skills in manual software testing including test case design, checklist creation, and bug reporting.

## Project Scope
The testing was performed on the iTaskApp web platform.

Tested modules include:
- User authentication
- Dashboard
- Task management
- Profile management
- Service requests
- Sharing functionality

## Testing Types
- Functional Testing
- UI Testing
- Cross-browser Testing
- Exploratory Testing

## Test Documentation

This repository contains:

### Test Cases
28 detailed manual test cases.

### Checklists
600+ testing checks covering different system modules.

### Bug Reports
Bug reports created during the testing process and documented in Jira format.
